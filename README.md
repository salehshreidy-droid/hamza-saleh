# Student A — Header & Hero

**Branch:** `feature/header-hero` (created from `dev`)

Owns the navigation header and hero section. `index.html` and `style.css` are an independent preview of Student A’s work. The CSS is the shared final stylesheet so the preview looks like the finished design; do not claim every CSS rule was written by Student A.

## Commands (after cloning the shared repository)
```bash
git switch dev
git pull origin dev
git switch -c feature/header-hero
# Add the header and hero content to the shared index.html and the matching styles to style.css
git add index.html style.css
git commit -m "Add header and hero section"
git push -u origin feature/header-hero
```
Open a Pull Request from `feature/header-hero` into `dev`, then have Student B review it. Do not replace the shared repository's index.html with this standalone preview: copy only your sections.
